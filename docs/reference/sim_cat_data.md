# Example simulated data with categorical DV

A simulated dataset with the 3 levels of categorical DV across 100
replicates.

## Usage

``` r
sim_cat_data
```

## Format

A data frame with 401400 rows and 4 variables:

- PID_code:

  Subject identifier

- IVAR:

  Time

- DV:

  Categorical DV with 3 levels

- Replicate:

  Replicate num for simulation
